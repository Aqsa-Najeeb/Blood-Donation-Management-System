# LIFE LINK — D4 Evidence Checklist

## Planning
- [ ] Review PRD, architecture, AGENTS and ADRs for contradictions.
- [ ] Create/maintain `plan.md` with objective, assumptions/open issues, vertical slices, priorities, dependencies, acceptance criteria/references and status.
- [ ] Preserve plan history (`plan-v01.md`, `plan-v02.md` or Git history).
- [ ] Keep all slice statuses truthful.

## Supporting artefacts
- [ ] API contracts.
- [ ] Data model/schema.
- [ ] UI wireframes/screens where useful.
- [ ] Component/module design.
- [ ] Test ideas/cases.
- [ ] Updated diagrams.

## Workflow evidence per slice
- [ ] Slice ID and linked requirements.
- [ ] Responsible member.
- [ ] Acceptance criteria.
- [ ] HITL/AFK mode.
- [ ] Actual AI chat/task reference.
- [ ] Iterations and major prompt/change.
- [ ] Test/check results.
- [ ] Human Accept/Revise/Reject decision.
- [ ] Major issue/change.
- [ ] Plan version and integration status.

Retain genuine AI chats, branches, rejected/revised approaches, failures/self-corrections and context/ADR changes.

## Validation/demo
- [ ] End-to-end checks for core FRs.
- [ ] Edge-case checks.
- [ ] NFR checks.
- [ ] Local deployment/demo instructions.
- [ ] Demonstrate product flows, plan history, vertical slices and one full implementation loop.
- [ ] Show revised/rejected AI output if it actually occurred.
- [ ] Show integration and test results.
- [ ] Explain CCP trade-off with evidence.
- [ ] Explain individual contributions.

## Final submission
- [ ] Working product/source.
- [ ] Latest PRD, architecture, AGENTS and ADRs.
- [ ] README, final plan and supporting artefacts.
- [ ] Plan history.
- [ ] Workflow evidence log.
- [ ] Final project report.
- [ ] Execution/deployment instructions/access info.
- [ ] Group contribution log.

## CCP report
- [ ] Problem statement.
- [ ] Complexity drivers.
- [ ] Trade-off.
- [ ] At least two alternatives.
- [ ] Integration approach.
- [ ] Evaluation metric/evidence.
- [ ] Scalability/feasibility.
- [ ] Ethical/societal impact.

**Not fabricated:** This archive contains no application source code. No implementation, tests, deployment, AI task references, human acceptance decisions or member contributions are invented.
